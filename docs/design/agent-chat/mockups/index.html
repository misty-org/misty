Agent chat: every state

One structure for everything an agent shows in a conversation, following Claude's desktop app. Click any line with a chevron to open it. Source files are named under each board.

  1. Working shimmers. Any live label (the thinking line, a group line, a running step) gets the gray sweep, with a small spinner beside a running step. No "…" dots.
  2. Steps are a table. Checklist, tool steps, sub-agents, plans, questions, app and screen requests, and unfinished work share one bordered table: a status icon and word, the thing itself, a short result on the right.
  3. The answer is the message. The final reply is plain formatted text in the transcript, never a banner, toast, card or error. A run that did not finish shows its answer, then a "Not finished" table.
  4. Icons and color carry meaning. Status icons (done, working, waiting, failed), brand logos for connected apps, item-type glyphs for files and docs, and amber / red for "needs you" and "failed". Every status keeps its word too, so color is never alone.
  5. Actions are buttons. Stop, Resume, Try again, Connect, Allow and the rest are real buttons (primary for the one that moves things forward), never underlined links.
  6. No raw text leaks. Tags such as [POINT:none], server markdown like "Still incomplete:" and raw error strings are parsed into the table, or dropped.
