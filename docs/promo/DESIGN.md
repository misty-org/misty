# Promo motion direction

Mode: Experience. The artifact is the 90-second feature walkthrough. The approved storyboard and monochrome Misty UI are authoritative.

- **Focal moment:** sequential workspace handoff. The original computer recedes, the device label changes, and the same recognizable page state appears on the laptop before scrolling resumes.
- **Continuity:** one Website launch project, consistent names and assets, and matching research tabs across scenes.
- **Feedback:** cursor arrival precedes menu selection, transfer progress follows copying, agent output follows submission, and restored state follows opening the remote workspace.
- **Budget:** deterministic React state; opacity and transforms; no live network or native operations. Encode 2,700 frames offline. No runtime video encoding in the viewer.
- **Copy:** feature labels and concrete actions only. No slogans, unverified superlatives, or performance comparisons.
- **Visual fidelity:** actual logo, Button and Avatar primitives, Lucide icons, monochrome theme; staged shell and feature compositions. Preview and recording provenance is explained in README.
- **Review:** use storyboard and transition contact sheets, then confirm the corrected render. Retain Inter as incumbent typography despite the generic-font detector warning.
