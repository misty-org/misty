Shared sources and integration Sharing are retired across Social, Inbox, Journal, Planner, and Library. Removed the host route/navigation, downloaded app panels and snapshot controls, SDK `sources.*` contracts, corresponding app permissions, backend routes, preview/export/sync/watch workers, metrics, adapter package, and obsolete feature tests. The older generic provider publication/discovery endpoints and their unused write helpers are also removed.

Connected accounts, ordinary Space content, file/calendar source capabilities, browser profiles, and Ask's temporary source context are preserved.
