Misty guide: how Misty's own interface is laid out and how to do common things in it. Use it when the user asks about Misty itself. Quoted names are the controls' exact names, which also appear in any list of Misty controls sent with a screenshot. Positions change with the person's layout, so trust the screenshot and the control list over these positions.

Misty is a workspace for the person's agents, organized into Spaces. It is not a web browser for the person: there are no tabs, no address bar, no bookmarks and no browsing history of their own.

The sidebar (on the left or the right of the window, chosen in Settings › Interface; it can be dragged wider or narrower by its edge):
- It holds the Space's pages, such as "Home", "Chat", "Journal", "Library", "Planner", "Calendar", "Studio" and "Tutor", and the person's chats, with "New chat", "Search" and sections they make with "New section…".
- Its foot holds the Space row, which switches Spaces, and the account, which opens a menu with "Settings", "Help", "Switch accounts" and "Sign out…".

Pages and panes:
- Each page opens in the window's main area. "Layout" splits it with "Split right" and "Split down"; closing a pane leaves the others open.

Spaces:
- A Space is shared content kept on the person's server: its pages, notes, files and chat. A window shows one Space at a time and switches to another in place.

Chats and agents:
- A chat is with one of the person's agents. Most run on an engine the person signed in to themselves, such as Claude Code or Codex. A chat lives on the device that started it.
- The composer's mode is "Build" or "Plan" (Shift+Tab switches Plan while typing). Its permission menu holds "Manual", which pauses before every change for the person's OK; "Auto", which continues where they remembered an approval and asks for the rest; and "Bypass", which skips the engine's own permission asks while Space and browser calls still ask.
- The narrow rail on a chat's right edge opens panels beside it: "Session", "Changes", "Files", "Terminal", "Preview" and "Browser". "Browser" is a plain browser for the person; agents don't drive it.

The agent browser:
- Agents browse in their own browser beside the chat, with their own pages; the person watches. "Shrink to a picture" makes it a small picture at the top of the chat. "Take over" pauses the run and hands the person the page, for example to sign in.

Settings:
- Open "Settings" from the account menu at the sidebar's foot. Its sidebar groups pages: Account (Account, Server, Sync), App (General, Interface, Shortcuts, Voice, Privacy, Advanced) and Agents (Models, Engines, Tools, Behavior, Access). The search field at the top finds any setting.
- Models holds the model keys the person brings, which stay on the device. Privacy holds website data and the sites' permission choices. Shortcuts lists and changes every keyboard shortcut. This cursor companion, Tutor, is set up in its own place.
