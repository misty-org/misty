Misty guide: how Misty's own interface is laid out and how to do common things in it. Use it when the user asks about Misty itself. Quoted names are the controls' exact names, which also appear in any list of Misty controls sent with a screenshot. Positions change with the person's layout, so trust the screenshot and the control list over these positions.

Misty is a workspace for the person's agents, organized into Spaces. It is not a web browser for the person: there are no tabs of their own, no address bar, no bookmarks and no browsing history.

The sidebar is the Space:
- Its top row switches between "Personal", the person's own private Space, and "Spaces", the Spaces they share with others. A dot on "Personal" means a direct message or a friend request is waiting.
- Under it: the Space's name, which opens its menu ("Invite people", its people, shared folders, renaming, leaving), then "Search", "Explore" (agent templates, apps, plugins, skills, prompts and connectors), the pinned places "Files", "Lab" and "Code" (their order is set with "Reorder pins"), and "Apps", every app the Space added.
- On Personal, "Friends" sits with those rows, and "Direct messages" lists people, then each of the person's agents as one long thread. A shared Space lists its "Channels" instead; "New channel" makes a text or a voice channel.
- The profile row at the foot opens the account menu with "Settings", "Help", "Switch accounts" and "Sign out…", and sets the person's status.

Spaces:
- A Space lives on the person's server: its chat, its files and the apps it added. Its files are also a drive on the computer, in Finder or File Explorer. A window shows one Space at a time.
- Calls: a voice channel is joined with one click on its row, and who is in it shows under it. A direct message can be called too. Calls are end-to-end encrypted. In a call, "Agents" brings the person's own agents in: everyone in the call can then talk to them by name (Hey Ada), and they answer in their own voice; "Leave" ends the call.

Chats and agents:
- An agent is one the person made: a name, instructions and an avatar, on one engine they signed in to, such as Claude Code or Codex. A chat lives on the device that started it, in a project folder or a scratch folder of its own.
- The composer offers the engine's own modes, by the engine's own names. Misty has no modes of its own.
- The narrow rail on a chat's edge opens panels beside it: "Session", "Steps", "Changes", "Files", "Terminal" and "Browser".
- Cmd+K finds chats, Space content, apps and settings, or runs a command. Cmd+L puts the cursor in the chat's message box and Cmd+F finds text in the chat.

The agent browser:
- Agents browse in their own browser beside the chat; the person watches. "Shrink to a picture" makes it a small picture over the chat. "Take over" pauses the run and hands the person the page, for example to sign in, and "Hand back" returns it to the agent.

The window:
- "Split right" opens a page beside the current one; closing a pane leaves the others open. Cmd+W closes the active tab and Cmd+Shift+N opens another window.
- On the Code page, Cmd+P finds a file in its folder by name.

Settings:
- Open "Settings" from the account menu, or with Cmd+Comma. Its groups: Account (Profile, Server), App (General, Interface, Input, Advanced) and Pages (Search, Code, Agents). The search field at the top finds any setting.
- Agents holds the person's agents, the default engine, Tutor, access and each engine's own setup. Input lists and changes every keyboard shortcut. Misty holds no keys: each engine keeps its own sign-in.
